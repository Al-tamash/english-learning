Explain technical work simply

6 patterns · 6 grammar rules · 6 mistakes · 10 phrases · 10 words. Client call se pehle 2 minute is sheet par eye scan karo, phir loud bolo.

Grammar quick rules

RuleExample
It's like + noun (comparison)It's like a shop address.
allow + person + to + verbThis allows you to update the site.
The problem is + noun/clauseThe problem is the large images.
mean(s) + noun/clauseIt means the page will load faster.
For example, + full sentenceFor example, you can pay online.
don't need to + base verb (≠ mustn't)You don't need to install anything.

6 patterns

1. It's like ___.

+ It's like a shop address for your website.

− It's not like a physical shop.

? What is it like?

2. This allows you to ___.

+ This allows you to update the website yourself.

− This doesn't allow you to change the design.

? What does this allow me to do?

3. The problem is ___.

+ The problem is the large images.

− The problem isn't the hosting.

? What is the problem?

4. It means ___.

+ It means the page will open faster.

− It doesn't mean the website is new.

? What does it mean?

5. For example, ___.

+ For example, a customer can pay online.

− Not every page needs a form.

? Can you give an example?

6. You don't need to ___.

+ You need to click save.

− You don't need to install anything.

? Do I need to do anything?

Common mistakes

WrongRightWhy
It's like to a shop. It's like a shop. like + noun, to nahi.
This allows you update. This allows you to update. allow + person + to + verb.
The problem is because the images. The problem is the images. The problem is + noun.
It means that is faster. It means the page will open faster. mean + clear clause.
You don't need install anything. You don't need to install anything. need to + base verb.
For example a customer can pay online For example, a customer can pay online. Example ko complete sentence banao.

Phrase bank

  • It's like rent for your website. — Ye aapki website ke kiraye jaisa hai.
  • This allows you to update the site. — Isse aap site update kar sakte hain.
  • The problem is the large images. — Problem badi images ki hai.
  • It means the page will open faster. — Iska matlab page jaldi khulega.
  • For example, you can pay online. — Jaise, aap online pay kar sakte hain.
  • You don't need to install anything. — Aapko kuch install karne ki zaroorat nahi.
  • It's the address people type. — Ye woh address hai jo log type karte hain.
  • The site is safe and secure. — Site safe aur secure hai.
  • We take a backup every night. — Hum har raat backup lete hain.
  • In simple words, it's faster. — Simple shabdon me, ye tez hai.

Words in action

  • hosting — website files rakhne ki jagah website hosting · Hosting is like rent for your website.
  • domain — website ka naam/address a domain name · The domain is your site's address.
  • responsive — har screen par fit a responsive website · The site is responsive on mobile.
  • load — khulna load faster · The page will load faster.
  • speed — raftaar page speed · Page speed matters for Google.
  • security — suraksha website security · Security keeps client data safe.
  • backup — copy jo safe rakhi jaye take a backup · We take a backup every night.
  • plugin — extra feature ka module a WordPress plugin · The plugin adds a contact form.
  • integration — do systems ka jodna payment integration · The payment integration is ready.
  • user — istemal karne wala a new user · A new user can sign up in a minute.

Pronunciation notes

  • Technical stress: HOSTing, doMAIN, reSPONsive, seCURity. Stress ek syllable par, baaki halke.
  • Integration: in-te-GRA-tion — stress third syllable par. ‘integration’ ko jaldi bolne ki koshish mat karo.
  • It's like: Linking: it's-like = /ɪtslaɪk/. Do words ko jodo, ruk kar mat bolo.
  • Contrast stress: The problem is the IMAGES, not the HOSTING. Contrast par stress badalta hai.
