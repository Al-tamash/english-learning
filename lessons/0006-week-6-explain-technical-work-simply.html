The 6 patterns

Pehle poora pattern bolo. Phir apni details me badal ke bolo. Suno button se model pronunciation sun sakte ho.

1. It's like ___.

Comparison se client ko turant idea milta hai.

+
It's like a shop address for your website.
−
It's not like a physical shop.
?
What is it like?
  • Hosting is like rent for your website.Hosting website ke kiraye jaisa hai.
  • A domain is like your shop's name board.Domain aapki dukaan ke naam ke board jaisa hai.

Grammar: It's like + noun. Comparison ke liye. Like yahan ‘pasand’ nahi, ‘jaisa’ hai.

Common mistake: “It's like to a shop” → “It's like a shop.” like ke baad noun, to nahi.

2. This allows you to ___.

Feature se client kya kar sakta hai.

+
This allows you to update the website yourself.
−
This doesn't allow you to change the design.
?
What does this allow me to do?
  • This allows you to add new products.Isse aap naye products add kar sakte hain.
  • The panel allows you to change photos.Panel se aap photos badal sakte hain.

Grammar: allow + person + to + verb. This allows you to... = isse aap kar sakte ho.

Common mistake: “This allows you update” → “This allows you to update.” allow ke baad to.

3. The problem is ___.

Problem ko seedha noun se bolo.

+
The problem is the large images.
−
The problem isn't the hosting.
?
What is the problem?
  • The problem is the old plugin.Problem purane plugin ki hai.
  • The problem is the slow server.Problem slow server ki hai.

Grammar: The problem is + noun/clause. Simple rakho: noun se shuru karo.

Common mistake: “The problem is because the images” → “The problem is the images.” because ki zaroorat nahi.

4. It means ___.

Technical baat ka client ke liye matlab.

+
It means the page will open faster.
−
It doesn't mean the website is new.
?
What does it mean?
  • It means your site is safe.Iska matlab aapki site safe hai.
  • It means Google can read your pages.Iska matlab Google aapke pages padh sakta hai.

Grammar: mean + noun/clause. It means = iska matlab hai.

Common mistake: “It means that is faster” → “It means the page will open faster.” Clear subject rakho.

5. For example, ___.

Abstract baat ko ek real example se jodo.

+
For example, a customer can pay online.
−
Not every page needs a form.
?
Can you give an example?
  • For example, you can change the price in one click.Jaise, aap ek click me price badal sakte hain.
  • For example, a new user can sign up in one minute.Jaise, naya user ek minute me sign up kar sakta hai.

Grammar: For example, + complete sentence. Comma ke baad sentence complete rakho.

Common mistake: “For example a customer can pay” → “For example, a customer can pay.” Example ko complete sentence banao.

6. You don't need to ___.

Client ko dar mat lagne do — kya nahi karna.

+
You need to click save.
−
You don't need to install anything.
?
Do I need to do anything?
  • You don't need to learn coding.Aapko coding seekhne ki zaroorat nahi.
  • You don't need to call the developer for this.Iske liye developer ko call karne ki zaroorat nahi.

Grammar: don't need to + base verb = zaroorat nahi. mustn't = mat karo — meaning different hai.

Common mistake: “You don't need install” → “You don't need to install.” need to + base verb.

Grammar corner

Ye rules Week 6 ke saare patterns cover karte hain. Ratta nahi — bolte time apply karo.

RuleExample
It's like + noun (comparison)It's like a shop address.
allow + person + to + verbThis allows you to update the site.
The problem is + noun/clauseThe problem is the large images.
mean(s) + noun/clauseIt means the page will load faster.
For example, + full sentenceFor example, you can pay online.
don't need to + base verb (≠ mustn't)You don't need to install anything.

Suno → 2 second pause → bolo. Do rounds: pehle text dekho, phir screen se nazar hatao.

Model dialogue

Shop owner client ko hosting samjha rahe ho. Riya = client. Jargon zero, comparison aur example use karo. Target lines ko apni details se replace karke bolo.

Riya

So why do I need hosting?

You

Hosting is like rent for your website. The files live on a server.

Riya

And the domain?

You

The domain is like your shop's name board. It's the address people type.

Riya

Will it be fast? Do I need to learn coding?

You

Yes, it will load faster. You don't need to install anything. For example, you can change a photo from your phone.

Technical answer se pehle ek comparison do, phir ek example. Client ko rule nahi, result chahiye.

Pronunciation quick check

Technical stress

HOSTing, doMAIN, reSPONsive, seCURity. Stress ek syllable par, baaki halke.

Integration

in-te-GRA-tion — stress third syllable par. ‘integration’ ko jaldi bolne ki koshish mat karo.

It's like

Linking: it's-like = /ɪtslaɪk/. Do words ko jodo, ruk kar mat bolo.

Contrast stress

The problem is the IMAGES, not the HOSTING. Contrast par stress badalta hai.
